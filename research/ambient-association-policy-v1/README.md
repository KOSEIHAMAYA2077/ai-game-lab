# 内容の連想と、形の命令を分ける

2026-10-03 JST。既存結果を読んだ後の設計分析であり、新しいモデル評価・実装・人間評価の結果ではない。既定 product、weights、threshold は変更していない。

**明示した形を正しく作る能力と、日常の文章から見て楽しめる形を連想する能力は、別に評価する必要がある。** 今ある小型処理を既定採用しない判断は維持する。その理由は、形の正解率だけではサイドインテリアの価値を測れない一方、作品として許容できる誤連想もまだ人に確かめていないからである。

文字の蓄積と流れる表面だけでも、日々の作業が形に残るという核を検証できる。内容による形選択は、その核へ加える別の寄与として調べる。視点や面の穏やかな変形、一定周期の形変更も、意味が分かった証拠とは別に扱う。

今回の結論は次の三点である。

1. 120 文 R1 full の 14/60 自動採用、140 文 static 128 guarded の 23/80、student guard-v2 の表現可能 strict 21/44 は異なる課題・fixture。合算せず、そのまま残す。成績を後から「連想なら正解だった」と改めない。
2. top-k は研究用候補として残せるが、top3 に正解があることと、自動変更して嬉しいことは別。現在の不採用を覆す根拠にはならない。
3. 次は内容反映なし・内容と無関係な同頻度変形・内容関連候補の比較を考える。文字面・ID・色・変化頻度を揃え、人の許容と邪魔さを別々に確かめる。この比較はまだ実施していない。

Gaver らは曖昧さを、作品と人の解釈の関係として論じ、明確な課題の遂行を妨げてよいとはしていない。ここから、表現の解釈は開いたまま、停止や取得範囲は明確にする、という区分を考えた。これは当研究への推測であり、Glyph Matter の有効性の実証ではない。[Ambiguity as a Resource for Design](https://studiolab.io.tudelft.nl/manila/gems/contextmapping/Gaver2003.pdf)
