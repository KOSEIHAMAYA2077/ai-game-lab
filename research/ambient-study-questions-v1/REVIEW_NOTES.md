# 独立読取レビューの反映

子担当 `study_design_review` が現方向 / HCI EVALUATION / R2境界を読み取り、編集・実行・UI・OS・network調査をせず返した指摘。主担当が新文書へ反映した。既存source、fixture、HCI文書の変更要求やテスト結果の更新ではない。

1. **live exposureの内生性**：表示が作業速度を変えると次の入力 / 形刺激も変わる。「100文字当たり」で割っても循環は解消しない。初回O/S/Mは固定人工状態、shape比較はtime-fixed master replay、本人との因果感は別試行とした。
2. **有限容量 / 未対応IME / 暫定履歴**：body256、doc512UTF16、unknownIME0、削除後の履歴保持が、8分 / 5日結果へ混入し得る。初回は同量上限内で開始し、容量 / noACK / 長いIMEを別QA、自由試行では方式が暫定と明示した。
3. **可視時間と自己選択**：嫌で隠した条件を可視時間だけの分母で良く見せない。予定時間内のhide / 中止と実数、可視時間を別併記。目視方向をeye tracking / 注意認証としない。

最小案は一種類の固定文書課題と等価3セット、6人の全6順序、独自短問と理由。文字追加・形候補・配置・明度・削除方式を同じ初回の要因へしない。課題と条件の均衡は前HCIの割当案を再利用して明示し、課題の等価性や持越し消失までは保証しない。

人間評価は依然0人 / 0回。資料の妥当性点検であり、参加者体験の採否ではない。主担当はその後の公開一次資料の部分読取を別に SOURCES / PRIMARY_NOTES に記録した。
