# 文字表面ウィジェットの研究課題と評価計画

2026-10-03。学生研究として実行できる範囲へ絞った**提案**であり、研究を完了したという報告ではない。既存アプリへのモデルの既定採用は見送る。試遊、OS全体の入力取得、新しい学習、追加モデル取得は、この文書作成では開始していない。

主RQは、**低資源の文字表面ウィジェットで、既知の6基本形を明示的に指定する日本語を、誤作動を抑えてどこまで正しく受理できるか**とする。「受理せず保留する」選択を含め、明示語規則、小型分類器、静的埋め込みを同じ入力と範囲で比べる。資源と文字の連続性は、使える方式を選ぶ制約および副評価に置く。

最新の用途は、創作・プログラミング・仕事の横で、入力した文字が材料として蓄積し、身体が育つサイドインテリアである。**全入力を命令として扱う前提にはしない。** 明示操作の研究は、その体験を支える一つの機能の評価に留まる。日常文章の内容を穏やかに映すambientモードは、正解が一つの命令課題と別に設計する。

## 絞り込みの判断

| 案 | 主張すること | 今回の扱い |

| 意味・描画効率・面の連続性の三つを同時に主RQにする | 多分野で優位な全体システム | 範囲が広く、現在の独立証拠を一つの改善率へまとめられないため選ばない |

副RQ1は、局所学習にない言い換えと保留対象で、特徴方式と共通の範囲規則がどの失敗を残すか。副RQ2は、入力時だけの解釈を文字の蓄積と分離し、表面と履歴を保ったままウィジェット予算で動かせるか、とする。

最小の次の一巡は、対象6形と比較入力を固定し、訓練・開発・最終未見集合を語彙と文型の群で分けること。その後に凍結した方式を評価し、実窓の資源測定と6人の形成的試遊を別に行う。既存120文・140文を見て変更した方式は、これらの文に対して未見性能とは呼ばない。
