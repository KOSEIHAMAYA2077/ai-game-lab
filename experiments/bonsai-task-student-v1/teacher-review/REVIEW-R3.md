# r3教師captionの独立点検

この結果はAIによる点検で、人間の正解ラベルではない。`teacher/raw-r3.jsonl` が120件に達した後、120返信すべてを各行の `sourceText` と元の `shape` に照らして点検した。rootのr3採否、学習済み予測、評価データ本文は参照していない。captionの修正・labelの付け替え・既存r2 reviewの変更は行っていない。

採用候補は57/120件で、除外は63件。すべて非空だった。採用57件のうち8件（index 14, 24, 28, 43, 49, 53, 68, 99）はsourceTextとの完全一致で、新しい言い換えではない。重複を除いた採用候補は49件。root側の独立採否との合意と、学習用データ内の重複除去を経る前の件数である。

| 判定 | 件数 |
| --- | ---: |
| 採用候補・sourceTextと異なる本文 | 49 |
| 採用候補・sourceTextとの完全一致 | 8 |
| 意味・幾何・用途が変わる | 13 |
| 生物・部位の取り違え | 3 |
| 主要幾何の欠落 | 10 |
| 対象を識別する情報が不足 | 11 |
| 不自然・崩れた日本語 | 16 |
| 形名などの短いlabelのみ | 7 |
| 説明や装飾付きの反復 | 2 |
| 外国語のみ | 1 |

r2と同じく、幾何または用途が保たれ、対象を識別できる日本語だけを採用候補とした。軽微な助詞の不自然さを許容したのはindex 8, 55, 56。すべての語句を残すことは要求せず、例えばindex 78は胴の細長さを省くが、両側のひれと扇状の尾が残るため採用候補とした。一方、index 46は上下の丸い面が等大という条件が欠けるため、円柱を別の丸い立体と区別できないと判断した。

index 0の球は「四角い固体」、index 83の爬虫類は「昆虫」、index 85のカメは「ハムスター」と取り違えているため除外した。index 41の「刃を持つ武器」、index 87の「虫を待つ節足動物」、index 102の「小さな飲み物用の器」は、対象を識別する情報が足りない。曖昧な返信を元のlabelへ無理に結び付けたり、欠けた特徴を補筆したりしていない。

「ボール」「正方形」「時計」「鳥」「カップ」「傘」といった短いlabelのみの返信は、有意な説明の拡張として採用しなかった。index 57は回答の説明と装飾付きの語句、index 112は原文の二重反復だった。余分な箇所を切り落とす修復をせず、返信全体を除外した。index 59の殻付きの卵の食品という短い説明は、殻と食品の文脈を含むため単独labelとは区別し、採用候補とした。

すべての `finish_reason` は `stop` で、`length` は0件だった。空返信、tool_call、混在言語は観測しなかった。外国語のみはindex 113の1件。非空率はr2の71/120からr3の120/120になったが、モデルとsystem promptの両方が変更されているため、モデル規模だけの効果や教師の一般的な優劣を示す比較ではない。また、採用率はstudentの意味精度や汎化性能ではない。

`decisions-r3.json` はindex 0〜119の順序を保つ120要素の配列で、各行に `accepted`, `reason`, `reasonCode`, `sourceDuplicate`, `textSha256` を記録した。`summary-r3.json` に集計と入力元SHA256を保存した。これらはrootと合意した行をtraining候補へ採用するための点検票で、このreviewだけで学習への採用を確定しない。
