# 独立した人工評価

凍結した244文をルール1方式・候補5方式で一度ずつ比較した。[評価結果と限界](REPORT.md)、[全1,464返信](predictions.jsonl)、[機械可読の指標](metrics.json)、[train/dev重複監査](overlap-summary.json)を参照。

名称なし描写はstatic-seed90/120、文字Bonsai8 33/120。ただしstatic-seedの否定への誤反応は19/20、文字Bonsai8の形あり文をholdとする取りこぼしは152/204だった。Bonsai文章追加は文字方式でseed比5件増、static方式は90/120のまま。評価後の調整はしていない。

これはAIが新たに作成し、AIが期待値を付けた人工評価である。人による評価、自然文分布から無作為抽出した評価、連想の楽しさの評価ではない。

`frozen-cases.jsonl` の期待値を、候補モデル・訓練データ・開発データ・モデル予測を見る前に固定した。`frozen-manifest.json` に件数、schema、凍結時刻、SHA-256を記録した。学習担当には、候補を凍結するまで件数・ハッシュ・schemaだけを伝える。

- 名称を使わない物・幾何の描写: 120文、既存60形につき2文。登録された対象名称・同義語の文字列が入らないことを事前確認した。対象以外の語が含まれる例はある。
- 明示した名称: 60文、既存60形につき1文。
- hold: 40文。直接の否定・取り消し20文、形と無関係な日常文20文。
- 独立した変形指定: 24文。長さ・幅・曲げの出力を形と分けて集計する。

描写が既存の近い複数形に当てはまる場合は `acceptedShapes` を設定した。名称はその形だけを許容する。具体物を引用や物語中で描くことも連想の入力として扱う。形を強く否定する文、形に無関係な文はhold。未知の具体物を必ずholdとする追加契約は設定していない。

lengthはshort/neutral/long、widthはnarrow/neutral/wide、bendはstraight/curved。追加の変形を指定しない時はneutral/neutral/straight。形自体に必要な自然な特徴（くびれや触手、通常の寸法関係等）は追加変形とは扱わない。

同一の元文から作った言い換えを学習・開発・評価へ分配していない。各文に作成元のfamilyを記録し、同familyを訓練側へ渡さない。独立作成でも一般的な名称や文型が偶然重なる可能性があるため、候補・データを凍結した後、訓練文との全文一致と部分フレーズ一致を監査する。一致を見て期待値を直したり候補を調整したりしない。

凍結後にラベル上の問題が見つかった場合は問題を報告し、元の期待値を保持する。形の正解率、holdへの誤反応、正形の取りこぼし、変形headごとの正解率を分ける。評価は既定アプリへの採用や人の好みを証明しない。
