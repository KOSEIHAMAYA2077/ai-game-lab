# 凍結した集計方法

この集計方法を候補の推論結果を見る前に定める。

同じ244文をstudent、seed baseline、root定義の既存ルールへ入力する。どの方式もトップ1の形とlength/width/bendを用いる。入力する現在形や状態で正解を補完せず、根拠のない出力はholdとする。ルールが複数形を返す場合は既存の順序の先頭を用い、候補数と集合も原票に保存する。

形は `acceptedShapes` のいずれかに一致すれば正解とする。主集計は名称なし描写120、明示名60、hold40、変形24の各枠。名称なし描写は60形のmacro正解率も示す。全244文の正解率と、形のある204文の正解率も示すが、主集計を置き換えない。

- holdへの誤反応: hold40文でhold以外を選んだ件数。否定・取消20と無関係20を別に示す。
- 取りこぼし: 形のある204文でholdを選んだ件数。間違った別形を出した件数とは分ける。
- 別形の選択: 形のある204文で、hold以外かつ許容集合の外を選んだ件数。
- 変形head精度: 形の正誤と独立して、変形24文のlength/width/bendごとの一致を数える。各ラベルの分母と、指定なしも含む全244文の値を補足する。形と変形3headすべて一致する数も示す。

モデルの推論時間は返されたmodelMsを補助的に集計する。端末・ウォームアップ・方式が違う可能性があるため、単独head推論時間を小窓全体の応答時間や資源使用量とは扱わない。

評価の全文、期待値、各方式の全出力を保存する。比較後の候補調整を行わず、凍結SHAを再確認する。評価担当は訓練データの作成・修正に参加しない。

凍結通知後の重複監査は、訓練・開発の各全文の完全一致、NFKCと空白・句読点除去後の一致、連続8文字以上の部分フレーズ一致を数える。部分一致は同義語や独立作成の一般的な文型でも起こるため、漏洩が確定した件数と呼ばない。12文字以上または短い方の文の40%以上を覆う一致を強い確認対象として別に示す。重複や疑わしい近似を見つけても、凍結した評価を修正せず該当原票を報告する。

訓練側familyと評価familyの識別子を照合する。文字列IDが違うだけで意味的な重複がないとは証明できない。作成経路の分離、全文監査、部分フレーズ監査の確認範囲を分けて報告する。
