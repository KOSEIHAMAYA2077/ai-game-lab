# R1 proposal frozen before artificial cases

The authoritative values are in [METHOD.json](METHOD.json). They are manually proposed comparison parameters, not fitted thresholds or measured comfort settings. Freeze that file's SHA before writing the streams.

This experiment starts after a synthetic source has supplied normalized accepted-material events. It neither connects to the earlier contract nor imports the widget. No OS, clipboard, real text, input permission, network, UI, renderer, model or Git is involved. Upstream known-commit quality is an assumption, not established here.

Three policies use the same lexical search for sphere/box/ring. Per-word analyzes each new word-like segment with no later-word lookahead. Batch analyzes a changed 6-second/128-unit window every 2 seconds. Batch+hysteresis uses two consecutive timed matches plus 5 seconds of minimum shape holding. An unchanged query may be sampled from cache for temporal consistency; that is not a second independent semantic observation. Neither repeated samples nor idle time refresh a keyword's 6-second expiry. Quotes and negation are deliberately not understood by this finite lexical search.

Material admission is independent of shape work and immediate within a 256-unit logical body. Unicode is not normalized; each insertion is segmented into grapheme units, each with a fresh ID and its batch color. Presentation is a cursor into that one body, limited to four units per 100 ms. Hidden/paused means no presentation or shape work, while material remains bounded. Reopening resumes small reveals and schedules one bounded catchup after 2 seconds instead of replaying every hidden word. Pause here pauses presentation/interpretation; it does not turn off material admission.

The default export has no raw text or text fingerprint. Volatile text is still needed for the artificial body and bounded lexical window. A separate explicit saving-on case can export only body text. Fixture files are manually authored synthetic inputs, not production recordings.

Focus and missing seq invalidate candidate context. Missing material is not reconstructed. Capacity refusal is explicit and never truncates an insertion. This downstream scheduler cannot make an unsupported API or ignored no-ACK lossless.

The outcome compares change frequency, actual search calls/cache samples, keyword-to-application latency, expiry/invalidation, bounded queues, and original unit/ID/color retention. Fewer changes do not establish comfort or better semantic behavior. Any changes after viewing results must be named R2 regression.
