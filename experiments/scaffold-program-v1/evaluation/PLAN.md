# 構造版 v1 の独立評価計画

旧バージョンと旧評価を保持し、新しい版だけを評価する。入力は日本語・英語の人工文 30 件で、実際のユーザー原稿は含めない。モデル・規則の初期調整へ評価本文を渡す前に凍結した。

## 意味の契約

構造の部位は最大 2 個、関係は最大 1 個。部位の配列順は文章に出る順ではなく、意味上の親→子。英語の「子 above 親」と日本語の「親の上に子」で、同じ親子関係へ正規化する。

- `end`: 親の +Y 側の先端へ子を接続する。
- `above`: 親より上に子を置く。
- `through`: 子が親を貫く。

部位は sphere/box/tube/blade/ring/vase の 6 種。寸法・曲がり・ねじれは制約内の値。これは任意メッシュ、任意数の部位、自由な動物の骨格を生成する評価ではない。

「首だけ細く、胴は太く」は vase の部位内パラメータには直接対応しない。今回の属性評価では球状の胴と管状の首を別部位として明示し、太さの修飾が正しい部位へ届くかを見る。

## 採点を分ける

| --- | ---: |
| 単部位 | 6 |
| end | 4 |

| 部位ごとの属性 | 4 |
| 否定 | 4 |
| 通常文 | 2 |
| 未対応・部位数超過 | 2 |

JSON/型の成立、部位の種類・個数、親子の方向、関係の種類、属性の対象と数値の方向を別集計する。正しいラベルを出しても、実際の肉付けで接続が切れたり対象が逆になれば幾何の確認は不合格。部位の抽出・語順正規化の規則と、学習した relation head の証拠を分ける。

最初の未見評価結果と生出力を保存する。結果を見て直した後の同じ fixture は回帰評価とし、新たな未見精度と呼ばない。公開される学習文と fixture の完全一致も調べ、重複があれば独立性の制限を記録する。

## 幾何と表示

- end: 接続用アンカー、子の位置、親の先端での接触を確認する。
- above: 親子の上下と、重なり/間隔を確認する。
- through: bbox overlap だけで合格にしない。輪の穴に親が入るだけの配置を、表面同士の交差として誤判定しない。実際の表面点や包含判定と画面を確認する。
- 文字の位置と面の向きが同じ部位変換を使うこと、有限な座標、文字の保持、接続部の破綻を確認する。

全工程の時間は入力送信から言葉の解釈、構造・肉付け、文字配置・表示と吸収完了まで測る。解釈だけを 3D 生成の総時間にしない。初回取得・モデル準備、キャッシュ後、生成時間は別記録。処理の速さと意味の正しさを分け、保留を新規生成成功に数えない。

現在の Mac での確認を一般的な 16GB ノート CPU/iGPU の達成証明としない。外部通信は固定した公式モデル取得と入力解釈中を分け、入力文を送っていないことも確認する。
