# 38形の表面を追加した比較

既存22形に、学習モデルを通さない手続き的な表面を38形追加した。素材・モデルのダウンロードはない。文字の材料、色、入力からの吸収は既存のものを使用する。文字が単なる輪郭線になる形だけを量産せず、面積のある身体を持たせた。

## 追加

円錐、円柱、カプセル、ピラミッド、宝石、八面体、ハート、卵、雫、三日月、雲、きのこ、葉、りんご、洋梨、かぼちゃ、巻き貝、魚、鳥、蛇、亀、蜘蛛、蓮、薔薇、太陽、雪の結晶、歯車、稲妻、瓶、カップ、ティーポット、傘、鐘、提灯、王冠、結び目、波、リボン。

回転体・楕円体・曲面・管・薄い面・複数部品を使い分けた。波は開いた面、結び目は閉じた管、ティーポットや生物は複数部品で構成する。文字IDと部品の対応は固定し、時刻によって部品を飛び移らない。動きはパラメータに沿う穏やかな流れで、物理的な流体シミュレーションではない。

## 検証

`expanded-surfaces.test.ts` は5件。38形の全64部品について、3種のseed、0/17/600/3600秒のサンプルで位置・接線が有限であること、座標範囲、微小時刻差での連続性を確認。周期方向の継ぎ目、形ごとの差異、出力領域の再利用も確認する。長時間のサンプルは実時間で1時間眺めた記録ではない。

`capture.mjs` は入力欄へ白色の文字材料を入力し、形メニューのクリックで全38形を切り替え、それぞれ4,096文字・12秒相当の時刻で撮影する。v1/v2/v3はいずれも38形すべてで有限な描画を確認し、ブラウザエラーと外部リクエストは0。v2は形の選択に意味語を混ぜない英数字の材料へ変更したため、初回との文字模様は異なる。

実行はリポジトリのルートから `node experiments/konjo-v1/surfaces/capture.mjs <新しい出力名>`。比較用画像は `python3 experiments/konjo-v1/surfaces/contact.py <出力名>` で並べる。4195で開発サーバーが動いていること、同梱のブラウザテスト依存関係、ローカルのChrome、画像一覧を作る場合はPillowが必要。

## 残る制限

語に対する任意の3Dモデル生成ではなく、用意した輪郭へ近い語を対応させる試作。生物・植物は抽象化された形で、解剖学的な模型や写実的な造形ではない。複数部品の内部の文字が透けること、視点によって花や道具の部品が重なって見えることがある。一般PCすべてでの性能、実OSの日本語IME、Windows、Safariはこの表面実験で確認していない。

3回目では鳥の翼が独立した葉のように見える問題を、尖った一続きの翼と尾へ変更した。薔薇は横向きで花びらが重なって塊に見えたため、花をこちらに傾けた。v3で鳥は翼と尾が見分けやすくなった。薔薇は依然として密な花状の塊に見えたため、この変更だけでは不十分と判断した。短い自然文と初期倍率64でも鳥833文字、薔薇897文字、ティーポット1,153文字、結び目961文字で有限に描画できた。文字数を黙って水増ししていない。

4回目は薔薇のみ、文字の25%を茎と2枚の葉へ割り当てて、花の輪郭を見分けられるようにした。[4,096文字](v4/rose.png) / [自然文897文字](v4-natural/rose.png)。どちらも実際に画面を確認し、有限な描画・エラー0・外部リクエスト0。撮影前後のソースハッシュも一致する。花は抽象化した造形であり、薔薇の写実的な花弁まで再現したという評価ではない。その他37形はv3から変更していない。

最終一覧の再作成は `python3 experiments/konjo-v1/surfaces/contact.py v3 v4`。元の撮影画像はそれぞれのディレクトリに保持している。
