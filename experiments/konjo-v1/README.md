# 根性版 v0.10 — 60の形と言葉のつながり

既存のv0.9を基点に、文字の表面描画と自由入力を残して形と言葉の対応を拡張した。モデル推論・外部APIを動作の前提にしない。元の4173/4194とその作業コピー・原稿・日記は変更せず、`feat/glyph-konjo-expansion-v1` と4195へ分岐している。

## 試す

`prototypes/glyph-creature` で `npm ci --ignore-scripts`、`npm run dev`。

- [通常画面](http://127.0.0.1:4195/): Enterで入力欄を開く。`白い文字でできたねじれた輪っか`、`白い文字が巻き貝の表面を流れる`、`赤い文字でできた鳥が羽ばたく`、`青い歯車`など。
- `輪っか`からメビウスと円環が候補になる。`ねじれた輪っか`ならメビウスへ絞る。`円環`のように名前を指定すればその形になる。
- `胡蝶`、`金剛石`、`稲光`などの同義語も使える。`花を生けるもの`、`ふわふわ`、`ぐるぐる`は作者が設定した連想から形を選ぶ。
- 形が疎い時は「＋文字」で直前の入力を足す。今回の形と入力色を保つ。倍率は従来の64回を維持し、HELPから変更できる。
- [専用の執筆欄](http://127.0.0.1:4195/?write)では文章を蓄積し、形に関わるフレーズで変更する。通常の追記では選択済みの形の保持時間を延長しない。

保存はブラウザのこのポート内。旧版とは別の保存領域で、既存の日記を自動移行しない。日記JSONの読込・書出しは保持する。他のアプリの入力取得はしない。

## 増やした形

22形へ次の38形を加えた。表示名違いを別の形として数えていない。

| 系統 | 追加形 |
|---|---|
| 立体 | 円錐、円柱、カプセル、ピラミッド、宝石、八面体、ハート、卵、雫 |
| 自然 | 三日月、雲、葉、きのこ、りんご、洋梨、かぼちゃ、蓮、薔薇、太陽、雪の結晶、波 |
| 動物 | 巻き貝、魚、鳥、蛇、亀、蜘蛛 |
| 道具・模様 | 歯車、稲妻、瓶、カップ、ティーポット、傘、鐘、提灯、王冠、結び目、リボン |

いずれも手書きの表面関数から点と接線を求め、文字の平面を載せて動かす。幾何・回転面・管・薄膜・部品の組合せを再利用しつつ輪郭を変えた。物理流体や新しい3D生成モデルではない。複数部品の重なり・開いた面の裏側・低密度では形が読みにくい部分がある。

[全38形の画像と比較記録](surfaces/README.md)。きのこ・歯車・傘・ティーポット・結び目などを同じ4096文字で比較。途中の鳥・薔薇・稲妻・魚・亀・三日月・葉・洋梨は輪郭を修正した。自然な文章の既定倍率での画像も別に保存している。

## 言葉をどう拾うか

1. 表記を正規化し、明確な形名と対応語を探す。同じ場所に重なる語は長いものを優先する。日付の「5月」と金額の「100円」、言葉に含まれる「葉」のような部分一致は形の指定にしない。
2. [WordNetから選んだ名詞同義語](lexicon/README.md)を探す。427行・404種類の語で、同じ語に複数の出典がある場合の重複行も含む。元資料のライセンス・ハッシュ・選択した意味IDを保存。語彙数は形状数と別に数える。
3. 名前がなければ[作者の連想グラフ](../../prototypes/glyph-creature/src/association-graph.ts)で概念間の関係を浅く辿る。「輪っか→輪の概念→ねじれた輪→メビウス」のような経路を持つ。辞書の客観的事実ではなく、本作の表現上の対応。特定の連想句の中ではその対応を優先する。
4. それでも候補がなければ、6文字以上の英語・4文字以上の仮名の綴りだけに限定した編集距離検索を使う。短い漢字や仮名へ強いあいまい一致は掛けない。
5. 明示した形名は文章内の候補を残し、同義語・連想・綴り補正側では根拠の近い最大4候補に絞る。送信時に候補から選び、弱い候補だけなら今の形を保つ。文字を描く毎フレームには検索しない。最近の解釈は小さなキャッシュで再利用する。

語彙表の行を単純に増やすと、単語の一部・否定・多義語による誤反応が増える。一般の文意を理解しているとは扱わない。局所的な「ではない」は避けるが、文全体の否定や照応は解けない。「春」を表すspringがコイルになる、「シェル」のソフトウェアの文で貝になるなど、[文脈依存6例](lexicon/round2/results.json)の反応を残した。

## 比較・修正と検証

- 形の初期画像v1、輪郭修正v2、鳥と薔薇の改善v3、薔薇へ茎と葉を加えたv4を保持して比較した。見た目の判定は担当エージェントの確認であり、人間の認識実験ではない。
- 辞書のboltを締結具へ対応させた初回の誤りを、実際の稲妻の描画と照合して修正した。誤対応したデータと修正理由は[initial](lexicon/initial/)に保持。
- 人工文50例のうち、採点条件を置いた44例は[round1](lexicon/round1/results.json)で43例通過。日付を月の形と読む誤反応を修正し、[round2](lexicon/round2/results.json)で44例通過。最終の字句処理でも[round3](lexicon/round3/results.json)で44例を再確認。残る6例は文脈依存の観察で、成功件数へ足していない。同義語の正解は候補に含まれることであり、候補が唯一正しいという意味ではない。調整に使った例であり未知評価ではない。
- 独立レビューで `word→sword`、`start→star` の誤字扱いと、日本語へ隣接する英語同義語の取りこぼしを発見。短い英語を綴り検索から除き、混在文の境界を修正した。否定の処理は近接した語だけで、文意全体の判定ではない。
- 単体92件、型検査、通常と筆画の2入口の配布ビルドを確認。
- 68件のブラウザ回帰を通過。最後の字句処理と薔薇の輪郭修正後は関連4ケースを再確認した。初回入力・追加の形・新語・色・執筆・日記・別窓・周期・停止・筆画を確認。IMEは合成イベントであり、実OSの日本語変換とは分ける。
- [最終ソースの短い観測](observation-v1/results.json): ティーポット・結び目・薔薇を各4096文字で、90フレーム準備後の360区間（各約6秒）観測。フレーム間隔中央値16.7ms、p95 16.7〜16.8ms。このMacのChrome154、1200×900/DPR1でのrequestAnimationFrame間隔であり、GPU実行時間や一般PCの保証ではない。別に1時間相当の時刻前進後の有限性と画像も保存。計測前後の主要8ソースのハッシュ一致。
- 入力・形変更のブラウザ検査でJS/consoleエラーと外部リクエスト0。通常入口でモデルのコード・重みを読み込まない。既存のモデル実験は保存するが、本作の判定には使わない。

一般的なWindows PC、Safari、実スマートフォン、本人の試遊は未確認。試行の画像と検証用の時刻前進を、実時間の長期観測とは呼ばない。

## 輪郭の別実験

既存文字の色とIDを保って輪郭を巡回させる比較は、`experiment/glyph-contour-v1` と4196の別版。球と立方体だけを最初の対象にし、この60形版の標準描画へは統合していない。
