# 形の断面をねじる、色を形から分ける

v0.13の構造版を残した `0.13.1-twist.1`。入口は[twist-v1](https://koseihamaya2077.github.io/glyph-matter/twist-v1/)、前の版は[program-v1](https://koseihamaya2077.github.io/glyph-matter/program-v1/)。同じ6部品と学習済み関係headで、文字の材料と形の構築を揃える比較。

元の実装と評価は[保存タグ v0.13](https://github.com/KOSEIHAMAYA2077/glyph-matter/tree/glyph-matter-v0.13.0-program.1)。mainの共通コードは新しい版になるので、元の動作を再現する場合は保存タグを使う。

最初はEnterでターミナル。HELPの「小型モデルを準備」で無料の公式モデルを取得し、端末内CPU/WASMで処理する。根性モードも選べる。文章をEnterで送ると、今までの文字と追加した文字が面へ流れる。色を明示すれば今回追加した文字だけがその色になる。

例: `白い細い棒の先に大きな球`、`黄色い箱を輪が貫く`、`ねじれた細長い刃`、`白いねじれた箱`。ドラッグで回転、スクロールで距離を変えられる。最大8,192文字。

## 何を変えたか

旧版のtwistは周囲の文字位置をずらす再パラメータ化だった。こちらは非円の断面を組み立ててから回転するので、箱や刃の形自体が中心線に沿ってねじれる。文字の接線も同じ面から計算する。全体回転や文字の流れとは分けている。

色が接続分類や未指定の形属性へ影響する問題を修正した。構造を解釈するコピーからだけ8色の語を除き、元の文字と描画色を維持する。部位・属性・関係を予測するencoder/head/caption/閾値は変更していない。[色を加えた186文の比較と初回失敗](model-color/README.md)。CPUと実ブラウザWorkerで186/186の全Programが色なしの文と一致。未知文章の正答率ではない。

接続は最大2部位＋1関係のまま。貫通は外接箱の重なりと区別し、実際の材料の境界を跨ぐかを確認する。極端寸法で管が小球を包む反例を見つけたため、成立を確認できる範囲へ制限する。最終受理範囲と実操作の結果は別の評価記録へ残す。

貫通の受理チェックは0・15・30・45秒の面を各時刻最大266点、合計最大1,064点調べ、親の材料の内側と外側に点がある場合だけ通す。早期終了と上限を持つ数値確認であり、全時刻・全寸法の形式的な保証ではない。証拠が得られない場合は既存の形へ文字だけを加える。調べた点数と時刻は `throughCheck` として記録する。

## 保存と次

元の根性版、骨格版、構造版のtagとURLを保持。失敗したheadの再学習も削除しない。入力は外部へ送らず、初回公式モデル取得は約128MB。出所・revision・SHA・ライセンスは[構造版のモデル記録](../scaffold-program-v1/model/README.md)。モデル準備と入力→吸収の全工程を分けて記録する。16GB laptop CPU/iGPUは目標実機であり、このMacの実測と混ぜない。

次の学習案は、対象部位と6点の断面半径を小さな予測器で求める方法。[一次資料と次の設計](../scaffold-program-v1/RESEARCH_NEXT.md)。この版で任意の未知物体や自由なメッシュを生成できるという主張はしない。

## 独立した比較と全工程の時間

[独立評価と再現用の記録](evaluation/REPORT.md)。以前の44文は前版と同じ出力で、色の独立12文・文字と色の履歴も実操作で確認。62操作は3.970〜4.027秒、描画例外と入力の外部通信は0。132単体テスト、型・本番build、新UIの2テストを確認した。

モデルを取得していない新しいブラウザでEnterを押すと、取得・検証・初期化・吸収演出まで12.213秒だった。最初の部分形成は8.263秒。30秒の許容には収まり、10秒目標は冷初回では未達。初回取得は約128MBで、回線によって変わる。キャッシュ済み準備は1.838秒。

通常の貫通18組をすべて維持し、極端な寸法を含む54組は39受理・15保留。受理39は独立した0〜120秒の10時刻で材料交差を確認した。保留を生成成功に数えない。約8,000文字の複合形2件はChromeのCPU4倍低速化で約4.09秒、実描画間隔中央値33.3ms（約30fps）。M5/32GBの確認であり、16GBノートPCの保証ではない。

残る視覚的な制限は、×64では面積の小さい細管が疎らになること、背の高い形で短い結果表示が上端と重なる場合があること。任意の自然文や未知の物体を生成する能力はまだない。対応した6部位・2部位以内と3関係の組み合わせを試す段階。
