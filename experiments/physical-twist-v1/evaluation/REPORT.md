# 物理断面のねじれ・色指定の独立評価

今回の変更では、箱と刃の断面そのものがねじれること、色指定が形の解釈を変えず今回の文字だけへ効くことを確認した。接続確認では時間経過後に交差を確認できない反例を見つけ、成立を確認できない組み合わせを保留する版へ修正した。既存44入力の出力は v0.13 と一致し、意味の評価に退行はなかった。

最新配布版の62操作はすべて有限の画面・10秒以内で完了した。別の冷初回入力は、モデル取得から吸収演出完了まで **12.213秒**。30秒の許容には収まり、10秒の目標は冷初回では達成していない。測定は M5・32GB の実機に限る。

## 評価の位置づけ

v0.13 の評価資料と試作は変更していない。以前評価した人工入力44例は回帰比較として再使用する。ここでの改善値を未知の自然文に対する初回精度と呼ばない。色の不変性を調べる12例は、構造解析から色を分離する変更前に別ファイルへ凍結した。本人の文章、日記、参考資料は評価へ使用していない。

新しい学習は行わず、関係ヘッドの重みは初回の SHA256 `2b5e212a7b8fec5cbf9683620ba7883c77e74140ccb65a1e91bc5ca1f5618a87` のまま。変更したのは、色を構造解析用のコピーから取り除く処理と、幾何断面の回転・接続の数値確認である。元の入力文と色は描画材料として維持する。

## 幾何を別の計算で確認

評価側は、描画側の断面内外判定を呼ばない。生成された点を共通拡縮・部位の座標系から戻し、曲線の法線平面を数値的に解いて断面の内外を判定する。非閉曲線は De Casteljau、輪は Hermite 形式を使う。物理的な断面回転を逆に戻し、楕円・角張った断面を判定する。花瓶では空洞を材料内部に数えない。

表面上に生成された別の80点で逆写像を校正した。最終54例の受理された39例では境界残差の最大値は `7.8e-12` 未満だった。単に外接箱が重なることを「貫く」の成功としていない。

「小さな輪を大きく曲がった細管が貫く」例では、最初の確認は0・30秒を通ったが、独立評価の15秒で管の表面1,024点すべてが輪の材料の外側になった。確認時刻を広げた版では、この組み合わせを保留する。最初の結果は上書きせず、`geometry-compatibility-after-guard.json` に残した。

最終評価時刻は `0 / 7.5 / 15 / 22.5 / 30 / 37.5 / 45 / 60 / 90 / 120` 秒。各時刻で子の表面1,024点を調べ、親の材料の内側と外側に両方の点があることを要求した。これで全時刻の39例が通ったが、有限の点と時刻の検査であり、連続時間・あらゆる寸法に対する保証ではない。

追加25例では、通常の「貫く」18/18、上に置く実際の表面点の接触3/3、先に付ける中心線端点の一致3/3を確認した。極端な太い管と小球の1例は保留となった。端点一致は、接合面全体が閉じることを証明するものではない。

箱と刃の断面にねじれを与えると、実際の表面点はねじれを与えない断面の境界から外れる。今回は文字の配置座標だけでなく、断面を計算した後で回転している。逆写像の偏差は内外判定式の値であり、物理的な変形距離の単位として扱わない。

## 色の独立評価

CPU側の凍結12例では、色なし・赤・黄色・青の各組み合わせについて、構造・保留理由・出力元が12/12一致した。基準となる3例もすべて要求した部位と関係に一致している。「全部保留だから同じ」という一致ではない。この数値はモデル解釈だけで、幾何構築・描画・吸収演出の時間を含まない。

同じ12例を実際のブラウザのモデル選択・入力欄・Enterから再操作した。構造・理由・出力元が12/12一致し、元の入力文と指定色も12/12維持した。

`白い細い棒の先に大きな球` は、細管（幅・奥行き0.4）と大球（高さ・幅・奥行き1.55）の接続に解釈され、新しい文字は白になった。続けて `青い球の上に箱` を入力すると、以前の白い文字を維持して、新しい文字だけが青になった。画像でも白と青が同じ形の表面へ混ざっていることを確認した。履歴の3操作でも、以前の文字・入力バッチ・色を3/3維持した。

## 確認の限界

- 内外判定は曲面を数値的に逆写像する方法であり、任意メッシュの符号付き距離や閉じたメッシュの証明ではない。非常に薄い材料や接線の根は取りこぼす可能性がある。
- 接続確認は有限の点と時刻で保守的に判断する。成立しない形を保留する一方で、成立する狭い接続まで保留する可能性もある。
- 日本語の実OS入力変換は自動テストの入力置換・Enter操作と別であり、この評価では確認していない。
- この実機は Apple M5・32GB RAM。16GBの一般的なノートPC・CPU・内蔵GPUでの測定ではない。4倍CPU低速化も、その実機やRAM容量の代替にはならない。
