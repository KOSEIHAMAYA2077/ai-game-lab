# 新小モデル・有限形契約の独立評価 R1

2026-10-03。評価担当が、新しい人工日本語文24件をモデルの返信を見る前に作成・固定する。

この比較は、文章から12種類の既知形と属性を選ぶ処理の検査である。任意の3D生成、文字の描画、実アプリ入力、快適性、語から形を連想する楽しさを達成したとは扱わない。

## 契約と件数

- 形名を明示する肯定依頼6件。
- 形名を含まない見た目・比喩の依頼6件。対象は作者が12候補から意図した一つであり、客観的な唯一解とは扱わない。
- 色・個数・動きが明示された複合依頼6件。
- 通常文、否定、コード、未知語、引用を含む hold 6件。

形は sphere / box / mobius / vase / sword / jellyfish / flower / fireworks / tree / bird / fish / snake。color は white / red / blue / yellow / green または null。count は整数1〜8。motion は still / flow / pulse または null。省略時は color=null、count=1、motion=null。hold は shape/color/motion=null、count=1に固定する。

自然物の一般的な色や動きを補うことは求めない。見た目説明の中にある「泳ぐ」「くねる」は、表現の flow 指定と区別する。個数は身体の数であり、羽や花びらなどの部位数ではない。形に対応できない場合は、属性だけを取り出して新しい形を想像しない。

## 分担と凍結

評価担当はモデルを起動せず、既存評価のfixture本文・モデル返信・失敗例を読まない。必須のrepo案内には過去の集計が含まれていたが、この24文の作成・閾値・期待値には使用していない。現在のユーザー入力や私的な文章は含めない。

rootとの契約相談で先に提示した2文は `consultation-examples-r1.json` に分離し、最終24文へ入れない。root は例文を含まない prompt と schema を先に固定した。評価担当は最終fixture本文を prompt の変更へ渡さず、path と SHA と件数だけ通知する。

rootが連絡した prompt のSHAは da0223fdfe8eab4c970b0054f901a3c5dfb042e54be13aebe5dea678e990d73d、schema は 76c700098619070b760a4169b7bb87c045142551d47474b24e499bf9de4ad774。これは担当から受けた固定情報であり、評価担当が実ファイルを再読して確認する場合は別に記録する。

`FREEZE-R1.json` が評価fixture、契約、相談記録、この方法、採点器、採点器の人工自己検査のSHAを固定する。モデル実行後に期待値や主指標を調整しない。誤りが見つかれば元の版を保持し、新しい版として記録して初回の独立評価とは分ける。

## 主指標

runnerの保存済みJSONLを採点する。各行は `{case_id, raw_text, status}` を含む。主指標は raw_text 全体が一つのJSONオブジェクトになり、契約の5キーだけを持ち、そのすべてが期待値と一致する件数 / 固定24件。

コード囲い、説明文、余分なキー、キーの重複、NaN/Infinity、booleanや浮動小数のcountは無効。前後の空白は許す。JSON抽出や修復によって主得点を上げない。停止・未実行・欠測・重複ID・runner失敗も得点0に含める。未知IDと壊れたJSONLは入力完全性の問題として別に示す。

補助指標は、形式を満たした返信数、各フィールドの正解数、群別の完全一致件数。すべてのフィールド分母は24件とし、無効返信を除いて良く見せない。false propose / false hold は形式が有効な返信だけで数えるため、これだけで安全性や再現率を主張しない。

## 限界

24件・人工日本語・一つの厳密契約であり、日本語一般や文章の感性を代表しない。各形の十分な類義語網羅もない。小モデルが意図したラベルを返しても、文字の表面が美しいこと、一般16GBノートで軽いこと、長時間利用で邪魔にならないことは別評価である。模型や形のモデル名による候補選びと、評価本文によるモデル調整を混ぜない。
