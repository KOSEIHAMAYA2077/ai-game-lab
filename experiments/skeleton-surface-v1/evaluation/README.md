# 独立評価：骨格＋表面 v1

ゲーム実装と入力解釈の担当とは別に、人工の日本語・英語 30 文と正解を先に固定した。実際の個人原稿は含まない。fixture の SHA-256 は `b80e07f6300ac7fcfde0a8349dfa3fa64b21df56266d2d9435a7b5feed6a46d3`。解釈担当へ評価本文は渡しておらず、この入力を学習・初期調整に使わない。

| 種類 | 文数 | 見るもの |
| --- | ---: | --- |
| 形の名称 | 6 | 6 形の直接指定 |
| 自然な言い換え | 8 | 名称を言わない日本語・英語 |
| 属性 | 8 | 高さ・幅・首・曲げ・ねじれの方向 |
| 否定 | 4 | 不要な形を選ばず、指定された形を読む |
| 通常文 | 2 | 関係のない日常文で形を捏造しない |
| 未対応対象 | 2 | 未対応の物体を対応済みと扱わない |

形状族の一致と、寸法などの属性条件の一致を別集計する。属性は数値の完全一致ではなく、意味に対応する方向と最低限の強さを確認する。`spec: null` が正しいケースでも、HTTP エラーや不正なレスポンスは成功としない。

## 計測範囲

**この API 評価だけでは「約 10 秒で 3D が生成・表示された」とは判定しない。** ここで測るのは HTTP 入力から解釈 JSON を受け取るまで。骨格・肉付け・文字配置・初回の完成した表示は別のブラウザ評価で確認する。生成全工程は 10 秒が目標で、30 秒までの待機と演出を許容する現在の条件は別に集計する。モデル読み込み、初回と暖機後も混ぜない。現在の実機結果を 16GB の一般ノート PC の確認済み性能としない。

解釈担当がモデル・説明文・属性規則を固定したことを確認してから、`evaluate.py --run-id initial --revision ...` を実行する。最初の結果は独立評価。結果を見て直した場合、同じ fixture での再測定は回帰結果と明記し、新たな未見精度と呼ばない。`fixture.json`、採点条件、最初の出力は上書きしない。
