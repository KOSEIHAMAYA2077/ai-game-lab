# Ambient shape retrieval v1

2026-10-03、現セッションで許可された独立CPU実験。所有はこのフォルダのみ。既定60形・根性resolver・Web/native描画・保存・OS入力を変更しない。入力は人工文だけ。目的は仕事や創作文から既知形の候補を過剰反応を抑えて返せるかを測ること。全入力が素材であることと、全入力を命令として扱うことを分ける。

既存の作者alias、選別WordNet名詞同synset、作者20node graph、疎特徴IDF統計を使用する。学習分類器・一般言語理解・任意3D生成ではない。ランタイムはCPUの純JavaScript、入力512 UTF-16 code unit以下、weightファイル8MiB以下。候補はproposalのみで、confidence不足なら現在形を保持する。

独立評価担当の新120文を読む前に、資料・人工開発文・方法・閾値・実装をSHAで凍結する。初回評価後のそのfixtureへの調整を禁止する。旧評価fixtureと失敗例は開発に使用しない。既存データのコピーには元のライセンスを添える。実機Windows16GB・実ウィジェット常駐・面白さ・意味理解は未検証。
