# Scoring protocol fixed before predictions

Fixture SHA256: `df7105b2f8bd134944ca2029fcd215eed987bc3164d5e06cd32bc49fa3409f45`.

Fixture and its intended meanings were authored before any source, model, corpus, or previous evaluation was read. Source inspection is allowed only after fixture freeze. This scoring adapter is created after schema inspection and before any predictions. It does not change expected intent.

- `sphere/box/cylinder/torus/blade/vase` map to `sphere/box/tube/ring/blade/vase`.
- Meaningful singleton: exact part count and shape are required. Meaningful pair: exact two shapes and requested relation and direction are required. `a below b` is equivalent to Program `b above a`. Left/right/inside/front/behind have no Program equivalent and remain unrepresentable; a hold is an intent miss but the appropriate conservative schema policy.
- Requested attribute checks use only authored fields. Dimensions are qualitative numeric checks in Program units, fixed here before predictions: small means every height/width/depth <= 0.8; large means all >= 1.2; tall/long height >= 1.5; short height <= 0.8; narrow width <= 0.7; wide width >= 1.2; shallow depth <= 0.8; torus thickness thin/thick means depth <= 0.8 / >= 1.2. These are evaluator thresholds, not model thresholds. Shape normalization and missing/mis-scoped attributes are reported separately. Unrequested dimensions are not asserted unchanged.
- A strict authored-intent render success requires structure and every annotated attribute. A structure-only score deliberately ignores dimensions. Clear hold and ambiguous cases pass only if `program === null`. A hold is never rescued with another interpreter.
- Full fixture accuracy includes 60 positive and 60 non-render cases. The schema-representable positive subset is 44 cases: 36 singletons + 8 above/below pairs. The remaining 16 positives report appropriate holds separately; they are not changed into hold annotations.
- Activation coverage is non-null Programs / all cases, and meaningful coverage is non-null Programs / 60 positives. False activation is non-null Programs on 40 clear hold or 20 ambiguous cases, reported separately and combined.
- Exact overlap is tested both as original whole text and NFKC/lowercase/whitespace-normalized whole text against train. Report with and without normalized exact overlaps. Development overlap is separate. Training noun/alias subspans can still be shared: zero whole-sentence overlap does not prove unseen primitive labels.
- Schema validation, compiler construction, and finite numerical surface sampling are separate from semantic accuracy. For each non-null Program, sample each compiled part at times 0, 10, 100 and seeds 1, 17, 64, with 64 IDs per seed/time (576 points per part), requiring finite points/derivatives. This does not validate perception, all animation poses, or an arbitrary mesh.
- Public runtime cold/import, warmed complete resolution, public primitive/relation score calls, offline exact base64/int16 decode loop, and wrapper classifier/guard timings are distinct. The wrapper `classifierMs` includes v1's authored preprocessing/scoping rules; `guardMs` includes the compiler. Offline decode loop timing is an auxiliary measurement, not added to measured totals. No UI/render/absorption/network/native-widget timing is claimed.

The evaluator has task-scope knowledge (six shapes and intended two-part approach) and authored synthetic examples rather than user traffic. It did not see the previous 90 cases before freeze. Prior guard-v2 work already reacted to those 90 cases, so this is a fresh fixture for this frozen wrapper, not a new model training comparison or arbitrary-language benchmark.
