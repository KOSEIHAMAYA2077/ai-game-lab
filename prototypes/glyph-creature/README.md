# 文字のかたち — Glyph Matter

別版: `glyph-creature-word-shapes-v0.9.0`。手動辞書と数式で22形状。ことばで形・流れ・色を組み合わせる、動く文字のコンセプトアート。

![文字が球の全面を覆う](../../experiments/surface-coverage-20260930/qa/final/sphere-2048-t12.png)

## 開く

Node.js 22.12系・24系・26以降のいずれかとWebGL2対応ブラウザを使用する。このフォルダで実行する。

```sh
npm ci
npm run dev
```

[http://127.0.0.1:4194/](http://127.0.0.1:4194/)を開く。自分の端末で起動した時のアドレスで、インターネット上の公開デモではない。停止は端末でCtrl+C。

## はじめ方

近くに浮かぶ `@` と、じわっと現れる `press enter` から始まる。最初のEnterで白枠の入力欄が開く。`enter word [enter]`の案内に沿って「エンター」や好きな文章を入れ、Enterで送ると動き出す。その後、画面下に「入力」「形」「? HELP」「書く」「一画」「日記」が現れる。

文章、日本語、英字、記号を自由に入力できる。変換確定後にEnterで送ると、入力欄の位置から文字が離れ、毎回少し違う螺旋で体に加わる。空白は粒にしない。「? HELP」の5つのヒントから、流れる球体、立方体の表面、色、動きの組み合わせを順に試せる。例は押して書き換えられる。

## 表面の流れ

`球体`・`流れる 球体`では文字が球の面全体を覆う。`流れる`を付けても、球体・立方体・直方体・団子は線や辺へ変わらない。文字の裏側の重なりは抑え、手前の面を見せる。

`表面 立方体`では文字が面に沿い、不規則に曲がりながら流れる。`表面 メビウスの輪`では文字の流れに加え、帯そのものの曲がり・幅・ねじれも変わる。`花火`はゆっくりずれながら広がる。文字を毎フレームランダムに動かすのではなく、連続した座標変形を重ねている。物理的な流体計算ではない。

[前の版との動画・比較と確認範囲](../../experiments/surface-flow-20260930/README.md)。

## ことばの組み合わせ

| 入力例 | 起こること |
| --- | --- |
| `夜空に赤い花火がひらく` | 文字が放射状に広がり、繰り返し花火を作る |
| `球体と立方体を思い浮かべる。青い文字が流れる。` | 球体か立方体を送信ごとに一つ選び、今回の文字を青にする |
| `流れる 球体` | 球の表面全体を文字が流れる |
| `流れる メビウスの輪` | 半ねじれの形に沿う細い一本の循環路 |
| `表面 メビウスの輪` | 帯の面全体に文字が流れる |
| `流れる 赤 四角形` | 四角い流路になり、この入力で増えた文字は赤のまま残る |
| `表面 黄色 立方体` | 箱の面に文字が流れ、この入力で増えた文字だけ黄色になる |
| `呼吸する 黄色い立方体` | 立方体がゆっくり膨らみ、縮む。色は今回の文字だけ |
| `流れる 波打つ メビウスの輪` | 循環しながら、輪が高さに応じてゆるくうねる |
| `表面 だんご` / `流れる だんご` | どちらも三つの球の面全体を巡る |
| `通常の動き` | 呼吸・波の追加変形だけを外す。文字と形は残る |
| `円 8個` | 8群に分かれた輪が空間内を動く |
| `円環 鎖` | 5個の輪が交互の向きで連なる。`8個`なども組み合わせ可能 |
| `円環 大小` | 大小2個の別々の輪。メビウスの位相変形ではない |
| `オメガ メビウスの輪` | 歪んだ輪へ変形する試み。Ω字形の厳密な再現ではない |
| `表面 直方体` / `流れる 十字` / `表面 三角形` | 対応する形の面または外周へ変わる |

メビウスのねじれと流れの位置は時間で変わる。形は団子・花火・球体・渦・原子軌道など22種類。球体・立方体・直方体・団子は両モードとも面を保つ。メビウス・円環・平面図形は既存の面／流路を選べる。渦・軌道・花火はそれぞれ固有の軌跡を使う。呼吸・波は形と組み合わせられ、指定しなければ前の動きを保つ。複数の動きが文にあれば一つを選ぶ。

色は白・赤・黄・青・水色・緑・紫・桃色。**色指定はその入力で追加した文字だけに効き、以前の文字を塗り替えない。** 指定した色は白へ戻らない。無指定なら従来どおり赤から約8秒で白へなじむ。入力欄の色選択でも指定できる。

形が見える量をすぐ試せるよう、入力の繰り返しは初期値64回。「×」で1・16・64・256回から選べる。個数指定とは別の操作であり、`円 8個`は繰り返しが64でも8個の輪を作る。短い入力を1回だけ追加した場合は、近くの小さなまとまりとして育つ。文字数が増えるほど広がり、数百文字で形の輪郭が見える。

対応する形や色を文中から拾い、複数あれば送信ごとに一つを選ぶ。「メビウスの輪」の「輪」などは重複候補から外す。これは対応語を組み合わせる仕組みで、一般的な文章理解ではない。指定しなかった項目は現在の状態を引き継ぎ、形を明示すると個数・配置を基本状態へ戻す。色だけの変更では配置も保持する。対応語が文章の一部に含まれると設定として解釈する場合があり、否定文や未知の物体には対応していない。文字列自体は材料として保持する。

## 対応語と形を増やした別版

花・蝶・くらげ・木・星・螺旋・砂時計・土星・剣・花瓶を追加。`白い文字がくらげの表面を流れる`、`表面 青い花瓶`、`波打つ 蝶`、`呼吸する 土星`などを組み合わせる。追加形は流れる指定でも面を保つ。形のボタンは三つの分類から選べる。

通常入口は手動の対応語だけで動き、分類モデルのコードや重みは読み込まない。旧版の学習コード・データ・重みは残している。`サイコロ`、`ドーナツ`、`ボール`などの別名も手動辞書へ追加した。[形の一覧・比較・確認・制限](../../experiments/word-shapes-v2/README.md)。

## 執筆と形の変化

[専用執筆欄](http://127.0.0.1:4194/?write)では、入力が350ms落ち着くと新しく書いた文字を1回ずつ加える。日本語変換中は待ち、確定後に追加する。Enterは改行で、取り込んだ行を二重に追加しない。「入力に合わせて追加」を外すと、従来どおりEnterで現在の行を加える方式になる。Shift+Enterは改行だけ。方式の切替はその後の入力に効き、原稿全体を一括追加しない。

通常は30秒ごとに別の形へ移る。文章に「球体」「メビウス」「立方体」「花火」などが現れるとその形に変わり、60秒保ってから自動変化へ戻る。同じ行に普通の文章を書き足しても、その期限を延ばさない。形の候補や流れの指定が変わった場合は読み直す。色だけの追記は自動変化を遅らせない。形ボタンにも60秒の優先時間がある。

自動変化は通常アート画面でも働く。「? HELP」の「形を自動で変える（30秒）」でオフにできる。停止中・タブ非表示・日記閲覧中は周期を止めるため、秒数は画面が動いている時間で数える。周期とオン・オフの設定は再読込で初期状態へ戻る。自動の順番は球体→立方体→メビウス→円環→直方体→団子→原子軌道→渦→花→蝶→くらげ→木→星→螺旋→砂時計→土星→剣→花瓶。花火は文章やボタンで指定したときだけ使う。

「別窓を開く」で小さな閲覧窓を開ける。対応ChromiumではDocument Picture-in-Pictureを使い、それ以外は通常の別窓。実際に確認したのは通常別窓の開閉とリアルタイム連携で、Document PiPの最前面表示は未確認。親の執筆ページを開いたまま使う。

**他のアプリで入力した文字を拾う機能、OS起動時の常駐はまだない。** 通常のWebだけでは他アプリ入力を受け取れない。[実現方法と次の選択肢](../../research/writing-companion.md)。

取り込んだ文字・形・色・時刻・乱数をこのブラウザに保存し、同じ日なら続きを復元する。日付は端末の暦日で、変わると前日の形を保存して新しい @ へ。直近14日を「日記」で再表示できる。保存失敗時は前日の状態を保持する。JSONと画像で書き出せる。書き出しJSONには渡した文章が含まれる。

原稿とカーソル位置も自動保存する。再読込・日付変更・形のリセットで原稿を消さず、復元した原稿は再び取り込まない。新しい追記だけが材料になる。原稿から文字を消しても、既に取り込んだ文字は身体に残る。「原稿を書き出す」でテキストとして残せる。原稿保存はUTF-16長1,000,000までで、保存エラー時も入力した文は切り捨てない。保存が壊れている場合は日記の「壊れた保存を退避して再開」から、元データを残して復旧できる。

「日記を開く」で書き出した一日分のJSON（8 MiB以下）を眺め直せる。日付が同じでも保存を上書きせず、「戻る」で直前の形へ戻る。原稿と既存の日記は保持し、閲覧中の形は別窓へ送らない。複数日をまとめたファイルの取込みや、自動で日記へ統合する機能はない。

通常アートの画面でも日記ボタンから手動保存できる。自動保存と日付切替は執筆モード。ブラウザの保存データを消すと原稿と日記も消える。執筆元は一つに限定し、二つ目の執筆タブは読むだけで開く。元のタブを閉じて「ここで続きを書く」で引き継げる。通常アートは同時に遊べるが、執筆中の日記を上書きしない。Web Locksに対応しないブラウザでは保存付き執筆を使えない。旧版のタブはこの保護に参加しないため、今回の版へ再読込して使う。

## 一画ずつほどく

[筆画の試作](http://127.0.0.1:4194/strokes.html)。あ・花・火・永・水・字・球の7文字を6文字まで組み合わせる。書く→ほどく→流す→戻す。KanjiVGの筆画データを同梱し、サーバーへの問い合わせなしで一画ごとに扱う。未収録文字は表示で知らせる。[調査とMARYの参照](../../research/strokes-and-word-play.md)。

同じ線を追えるよう、切り替え時の拡縮・移動・回転をつないでいる。長く流した後も何周も巻き戻らず文字へ戻る。書きかけでほどくと、残りの筆順を続けながら散らばる。「書く」はもう一度、筆順を最初から再生する。

## その他の操作

- Escで閉じる。下書きは次に開くまで残る。送信後も入力欄は閉じる。
- 空間のドラッグで回転、スクロールで距離を調整。タッチでは軽くタップして入力欄を開く。
- 「入力 / 操作」に4つの従来形状ボタン、「もう一度」「止める／動かす」「最初へ」を置く。
- 文字は厚さゼロの平面として回転・拡縮する。球・立方体・直方体・メビウス・団子の単体は文字数に応じて面へ姿勢を寄せる。閉じた立体の裏側は隠れ、少数文字とメビウスなどの開いた面は両面を見せる。

## 範囲と制限

入力の外部送信、大容量モデルの追加取得、課金はない。[無料小型AIの実験](../../concepts/glyph-creature/LOCAL_AI_RESEARCH.md)では端末内推論まで確認したが、意味の誤りが残り採用を見送った。ネット検索から任意の形を理解して3D化する機能は未実装。

合計32,000文字、異なる文字は1,024種類、形の個数は1〜16まで。通常ターミナルの一回の入力が16,384 UTF-16コード単位を超える場合は切断せず断る。執筆の逐次追加では長い貼り付けを分割して上限まで取り込み、原稿自体は残す。形の解釈は現在の行（複数行の貼り付けはその追加部分）の末尾16,384単位まで。結合文字はNFCで正規化し、書記素クラスタで保持する。表示はOSのフォントに依存する。

通常アートは再読み込みで状態が消えるが、日記で手動保存できる。執筆モードは当日の保存状態を復元する。流体の物理計算ではなく、数式による軌跡と変形。字形そのものを曲面に沿って曲げる処理、任意画像からの立体化、クイズ、実績／図鑑、ゲーム経済は未実装。

ブラウザテストは通常のChromeを使用する。他の環境にブラウザがない場合は`npx playwright install chromium`で用意する。具体的な結果は[確認記録](evidence/README.md)へ。

開発版だけに`window.__GLYPH_ART__`の状態取得・時刻前進・リセットを用意している。通常操作のテストと併用し、内部状態だけで成功としない。吸収のseedは入力ごとに変え、指定seedでの計算は再現可能。
