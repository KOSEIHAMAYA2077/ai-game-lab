# 文字のかたち — Glyph Matter

`glyph-creature-p0-v0.1.0` / 動くコンセプトアートの最初の試作。

![文字の集合でできたメビウスの輪](evidence/new-characters.png)

自由に入れた文字が、凝縮する塊・渦・原子軌道・メビウスの輪を作って流れる。追加した文字は赤く入り、約8秒で白へなじむ。蓄積すると密度と全体の大きさが増し、カメラが引く。

## 開く

Node.js 22.12系・24系・26以降のいずれかと、WebGL2対応のブラウザを使用する。このフォルダで次を実行する。

```sh
npm ci
npm run dev
```

[http://127.0.0.1:4173/](http://127.0.0.1:4173/)を開く。これは自分の端末で起動した時のアドレスで、インターネット上の公開デモではない。起動を止める時は端末でCtrl+C。

## 操作

- 下の欄へ日本語・英字・記号を入力し、「加える」または変換確定後のEnter。
- 「一度に重ねる」で1・16・64・256回を選ぶと、同じ入力をまとめて追加できる。
- 「前の文字をもう一度」で直前の入力を追加する。
- 上の4ボタンで形を切り替える。文字は消えず、同じ集合が別の形へ移る。
- 観察領域をドラッグすると回転、スクロールすると距離を調整できる。
- 一時停止と「最初から」を用意。初期画面のサンプルボタンから約1,200文字の流れも試せる。

## 初回の範囲と制限

合計32,000文字、異なる文字は1,024種類まで。一回の入力が16,384 UTF-16コード単位を超える場合は切断せず、追加を断って案内する。空白・改行だけの入力は粒にしない。結合文字はNFCで正規化し、書記素クラスタとして保持する。

入力の内容は外部サービスへ送信しない。ページを閉じたり再読み込みすると状態は消える。文字は画面を向く板状の描画なので、曲面に沿って字形自体が曲がる表現はまだ行わない。日本語の表示はOSに入っているフォントに依存し、環境にない字形や絵文字は代替表示になる場合がある。

語義から自由な形を生成するモデル、団子の形、ゲームの経済・勝敗は未実装。今回の4形状は数式で作っている。流体の物理シミュレーションではなく、循環する文字の軌跡による表現。

## 確認と開発

```sh
npm test
npm run build
npm run test:e2e
```

ブラウザテストは、このMacに通常のChromeがあれば使う。他の環境でテスト用ブラウザがない場合は、`npx playwright install chromium`で用意する。確認結果と未確認環境は[作品の進捗](../../concepts/glyph-creature/PROGRESS.md)に記録。

`npm run build`は配布用の`dist/`を作る。配布用の確認は`npm run preview`。開発版の停止後に実行する。distを開く場合もHTTPサーバーを使用し、index.htmlの直接ダブルクリックは使わない。

開発版だけに`window.__GLYPH_ART__`の状態取得・時刻前進・リセットを用意している。通常操作を経由するブラウザテストと併用し、内部状態の直接変更だけで成功としない。

素材: OSの既存フォント、文字・図形、Three.js。新しい画像・3Dモデル・音の素材は使用していない。参考画像や添付本は含めない。[Three.jsの利用条件](public/THIRD_PARTY_NOTICES.txt)を配布物へ同梱する。
