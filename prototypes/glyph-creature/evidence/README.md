Codex内ブラウザでもEnterでの開閉、入力・送信後の表示を確認した。平面の表裏は開発用の向き固定で画素を比較し、通常時間による回転・拡縮も別に確認した。日本語入力の合成イベントは確認したが、実OSのIMEでの変換操作は未確認。Windows・Safari・スマートフォン実機も未確認。試作の意図への適合は本人の試遊で判断する。
