画面記録は開発用時刻前進も併用した。ランダムな吸収は試験ごとに変わるため、特定の1枚を全実行の固定表示とはしない。32,000文字の通常アニメーションも別途動かし、30フレームの短い観測で中央値約16.7msだった。

今回の回帰確認では、色だけの入力で配置が消えないこと、大小から8個へ変更できること、飛翔中の形変更で位置が跳ばないことも確認した。入力中の外部通信はなし。日本語IMEの合成イベントは確認したが、実OSの変換操作・Windows・Safariは未確認。表現の良し悪しは本人の試遊で判断する。
